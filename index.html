Live Personal product · iOS & Android

MealChime

A real-time family meal-ordering app. The cook posts breakfast, lunch or dinner, everyone fills their plate from their phone, and each person gets a chime when their plate is ready.

  • React Native and Expo client in TypeScript, with an ASP.NET Core API on .NET 10, Entity Framework Core and PostgreSQL 17
  • SignalR queue pushes live order status to every device; JWT auth through ASP.NET Identity
  • Runs on Azure App Service and Azure Database for PostgreSQL, with all infrastructure defined in Bicep and Azure Monitor alerting
  • GitHub Actions runs 63 xUnit integration tests and deploys on push, signing in to Azure with no stored secrets

Personal product · iOS, Android & web

Memento

A booking app for tattoo and piercing artists. Customers find studios nearby, browse artist portfolios and book open time slots, while artists run their own profiles, services, prices and hours.

  • React Native (Expo) and TypeScript app on Supabase: Postgres with PostGIS for nearby search, row-level security, Edge Functions and Realtime
  • Full booking flow: real availability with no double-booking, signed digital intake and consent forms, aftercare reminders and two-factor sign-in
  • 3D tattoo placement built with three.js, previewing a design on the body at its true size
